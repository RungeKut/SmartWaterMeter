# SmartWaterMeter — Документация проекта

> **Назначение:** Эта документация предназначена в первую очередь для **GigaCode/GigaCod** — ИИ-агента, работающего над проектом. Она спроектирована так, чтобы минимизировать объём контекстного окна: каждый файл посвящён одной теме, читать нужно только то, что относится к текущей задаче.

---

## Правила использования и обновления документации

### Для GigaCode

1. **При старте работы над проектом** — прочитай `_index.md` (этот файл). Он содержит карту документации и правила.
2. **Для понимания конкретного модуля** — читай только соответствующий файл из `docs/modules/*.md`. Не читай всё подряд.
3. **Для понимания протокола WebSocket** — `docs/websocket.md`.
4. **Для истории изменений** — `docs/CHAT_SUMMARY.md` (или корневой `CHAT_SUMMARY.md`).
4a. **Перед крупной переделкой** — загляни в `docs/sessions/`: там разбор прошлых заходов, включая то, что выглядело исправным, но не работало.
5. **После завершения задачи** — обнови соответствующий файл документации, если он устарел. Также дополни `CHAT_SUMMARY.md` записью о сделанных изменениях.

### Для разработчика

1. **Никогда не редактируй `docs/_index.md`** вручную при добавлении/удалении модулей — скажи GigaCode обновить карту.
2. При добавлении нового модуля в `src/`:
   - Создай `docs/modules/<name>.md` с описанием его полей и методов
   - Попроси GigaCode обновить `docs/_index.md` — добавить ссылку в карту
3. При изменении логики модуля — обнови его `docs/modules/<name>.md`.
4. После каждого значимого изменения — допиши запись в `CHAT_SUMMARY.md`.

## Как обновлять документацию

### Добавление нового модуля

1. Создай файл `docs/modules/<name>.md`
2. Добавь строку в таблицу в `docs/_index.md`
3. Сделай коммит

### Обновление существующего модуля

1. Отредактируй соответствующий файл в `docs/modules/`
2. Если изменения повлияли на другие части системы — обнови и их
3. Допиши запись в `CHAT_SUMMARY.md`

### Удаление модуля

1. Удали файл из `docs/modules/`
2. Удали строку из таблицы в `docs/_index.md`
3. Сделай коммит

**Важно:** Обновляй документацию сразу после изменения кода, не откладывай. Пять минут сейчас сэкономят час контекстного окна потом.
