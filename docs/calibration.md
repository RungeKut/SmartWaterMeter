# SmartWaterMeter — Калибровка датчиков DS18B20

## Назначение

Калибровка привязывает физический датчик DS18B20 к логическому каналу (Cold/Hot/Return/Supply) без редактирования `secrets.h`. Адрес датчика сохраняется в EEPROM.

## Процесс пошагово

1. Подключите **один** датчик, который хотите откалибровать
2. Откройте веб-интерфейс, вкладка **Calibrate**
3. Убедитесь, что датчик отображается в таблице **Bus Sensors**. Если его нет — подождите до 30 секунд (список обновляется автоматически). Отдельно ждать не обязательно: рескан шины выполняется и при нажатии **Calibrate**
4. Нажмите **Calibrate** на нужном канале
5. Нагрейте физический датчик (пальцем, феном и т.п.) более чем на 5°C
6. Когда разница достигнет порога — адрес сохранится автоматически, в веб-интерфейсе появится зелёная плашка
7. Повторите для остальных датчиков (только по одному за раз!)

## Параметры

| Параметр | Значение | Описание |
|----------|---------|----------|
| `CALIBRATE_THRESHOLD` | 5.0 °C | Минимальный нагрев для фиксации |
| `CALIBRATE_TIMEOUT` | 60000 мс (60 с) | Таймаут на нагрев |
| Интервал опроса | 1000 мс | Тот же, что в обычном режиме |

## Индикация

- LED: **горит постоянно** — идёт калибровка
- Веб-интерфейс: кнопка меняется на "Calibrating...", таблица шины показывает дельту температур

## Если калибровка не удалась

- **Таймаут (60 секунд):** датчик не нагрелся на 5°C — попробуйте снова
- **Нет датчиков на шине:** проверьте подключение — в таблице Bus Sensors должно быть хотя бы одно устройство
- **Датчик не появляется в таблице Bus Sensors:** подождите до 30 секунд или переоткройте страницу (список шины обновляется раз в 30 секунд; см. `docs/pitfalls.md` раздел "Обновление списка датчиков на шине")

## Внутреннее устройство

```cpp
startCalibration(index):
  1. rescanBusLight() — обновить _allAddrs[] через DallasTemperature API
  2. Проверить, что на шине есть хотя бы одно устройство
  3. Сбросить _calibrateBaseReady и весь массив _calibrateBaseTemp[]
  4. Запомнить время старта, установить _calibrating = true

readTemperatures() (первый вызов после старта):
  5. Снять базовые температуры, _calibrateBaseReady = true

readTemperatures() → checkCalibration():
  1. Для каждого датчика на шине:
     delta = currentTemp - baseTemp
     если delta >= CALIBRATE_THRESHOLD:
       - Скопировать адрес в _expectedAddrs[_calibrateIndex]
       - Сохранить в EEPROM через ConfigStore::setSensorAddr()
       - Вызвать callback(success=true)
  2. Если прошло > CALIBRATE_TIMEOUT:
     - Вызвать callback(success=false)
```
