# SmartWaterMeter — Фронтенд (SPA)

## Общая информация

- **Файл:** `data/index.html`
- **Тип:** Single Page Application (вся логика в одном HTML)
- **Стиль:** Material Design + Dark Mode (через `prefers-color-scheme`)
- **Веб-сервер:** отдаётся статически из LittleFS без кеширования

## Страницы (вкладки)

### Dashboard (Главная)

Отображает:
- Температуры 4 датчиков (Cold, Hot, Return, Supply)
- Показания счётчиков (ГВС/ХВС) в м³
- Статус системы:
  - WiFi: Connected/Disconnected/AP mode + RSSI
  - IP-адрес: в AP-режиме показывает SSID точки доступа, иначе IP
  - Uptime, Free heap, текущее время
- OTA-баннер с обратным отсчётом (если прошивка не подтверждена)

### Settings (Настройки)

Поля:
- WiFi: SSID, пароль
- SMTP: хост, порт, email, пароль, получатель
- Расписание отчётов: час, минута, тип (daily/weekly/monthly), день
- Счётчики: начальные показания (м³), литры на импульс (ГВС/ХВС)

Кнопка **Save & Reboot** — отправляет конфигурацию, устройство перезагружается.

### Calibrate (Калибровка)

Две карточки:
1. **Bus Sensors** — таблица всех устройств на шине 1-Wire:
   - Индекс на шине, адрес (hex), температура, дельта (при калибровке)
2. **Calibration** — кнопки для каждого канала (Cold/Hot/Return/Supply):
   - Статус (Found/Missing), текущая температура
   - Кнопка "Calibrate" / "Calibrating..."

## Технические детали

- WebSocket: авто-подключение при загрузке, auto-reconnect каждые 3 секунды
- Все данные обновляются в реальном времени через WebSocket
- При переподключении — запрос `getFullState` для получения полной конфигурации
- Toast-уведомления для действий (сохранение, калибровка, email)
- Dashboard в AP-режиме: в поле IP отображается SSID точки доступа
