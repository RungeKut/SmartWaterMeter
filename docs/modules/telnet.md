# TelnetSerial.h — Telnet-консоль

## Назначение

Дублирование вывода `Serial` в Telnet (TCP:23) и обработка команд.

## Как работает

Использует `os_install_putc1()` из SDK ESP8266 для перехвата **всего** вывода (Serial.print, printf) и дублирования во все подключённые Telnet-клиенты (до 4 одновременных).

## Команды

| Команда | Описание |
|---------|----------|
| `help` | Список команд |
| `status` | WiFi, IP, аптайм, heap |
| `reset` / `restart` | Перезагрузка |
| `heap` | Свободная память |
| `uptime` | Время работы |
| `confirm` | Подтверждение OTA-прошивки |

## Методы

| Метод | Описание |
|-------|----------|
| `begin()` | Установка хука putc1, запуск TCP:23 |
| `handle()` | Вызов в `loop()`: приём клиентов, команды |

## Безопасность

Простое текстовое соединение, без пароля. Только для доверенной сети.
