# FailsafeOTA.h — Безопасное OTA-обновление

## Назначение

Защита от brick-прошивки при OTA. Автоматический откат, если прошивка не подтверждена.

## Механизм

1. OTA пишет прошивку в неактивный слот (A: 0x10000 / B: 0x101000)
2. ESP8266 перезагружается в новый слот
3. RTC memory: пишется флаг "ожидание подтверждения"
4. Таймер на 5 минут
5. Если пользователь подтвердил (веб-интерфейс или Telnet) — флаг снимается
6. Если нет — откат на старый слот и перезагрузка

## Защита от bootloop

Если устройство перезагружается 3 раза без подтверждения — FailsafeOTA автоматически откатывается.

## Методы

| Метод | Описание |
|-------|----------|
| `begin()` | Инициализация, проверка RTC-флага, определение слота |
| `handle()` | Проверка таймаута в `loop()` |
| `confirm()` | Подтверждение прошивки |
| `isPending()` | Ожидание подтверждения? |
| `remainingSec()` | Секунд до отката |
| `getSlot()` | Номер текущего слота (0 или 1) |
