# SmartWaterMeter — Аппаратное обеспечение

## Платформа

| Параметр | Значение |
|----------|---------|
| Плата | Wemos D1 mini (ESP8266EX) |
| Частота | 80 MHz |
| RAM | 80 KB (доступно ~43 KB) |
| Flash | 4 MB (прошивка ~1MB + LittleFS 2MB + EEPROM 4KB) |
| Разметка | `eagle.flash.4m2m.ld` |

## Назначение пинов

| Компонент | Пин | GPIO | Режим |
|-----------|-----|------|-------|
| DS18B20 Data | D3 | GPIO0 | 1-Wire |
| Счётчик ГВС (импульсы) | D5 | GPIO14 | INPUT_PULLUP, прерывание CHANGE |
| Счётчик ХВС (импульсы) | D6 | GPIO12 | INPUT_PULLUP, прерывание CHANGE |
| Встроенный LED | D4 | GPIO2 | OUTPUT (LOW = ON) |

## Датчики температуры DS18B20

Четыре датчика на одной шине 1-Wire (GPIO0). Подтяжка к питанию — внешний резистор 4.7 кОм.

### Маппинг каналов

| Индекс | Имя | Назначение |
|--------|-----|------------|
| 0 | Cold | ХВС (холодная вода) |
| 1 | Hot | ГВС (горячая вода) |
| 2 | Return | Обратка отопления |
| 3 | Supply | Подача отопления |

### Адресация

Адреса DS18B20 хранятся:
1. В EEPROM (после калибровки) — приоритет
2. В `secrets.h` (константа `SENSOR_ADDR[4][8]`) — fallback

При старте `TemperatureSensors::begin()`:
- Сначала проверяет EEPROM
- Если адрес из EEPROM не найден на шине — пробует `secrets.h`
- Если `secrets.h` подошёл — сохраняет адрес обратно в EEPROM

## Счётчики воды

Герконовые счётчики (геркон замыкает при каждом литре/импульсе).

### Параметры

- Подтяжка: INPUT_PULLUP (внешняя не требуется)
- Антидребезг: 5 мс на замыкание, 50 мс на размыкание (настраивается в веб-интерфейсе)
- Коэффициент: `litersPerPulse` — настраивается в веб-интерфейсе, задаётся **в литрах** на импульс (по умолчанию 1.0 л/имп = 1000 имп/м³)

Показания хранятся в м³, поэтому `process()` делит на 1000:

```cpp
float totalM3 = (count * litersPerPulse) / 1000.0f;
```

### Алгоритм подсчёта

Захват фронтов в прерывании (кольцевой буфер), разбор автоматом в `loop()`:

- замыкание подтверждается, если LOW держится ≥ `debounceClosedMs` (5 мс)
- размыкание — если HIGH держится ≥ `debounceOpenMs` (50 мс)
- импульс засчитывается по завершению подтверждённой замкнутой фазы

Пороги настраиваются в веб-интерфейсе. Подробности и обоснование — в [modules/meters.md](modules/meters.md).

### Особенность старта

При включении текущее положение геркона принимается как исходное состояние. Если он замкнут, импульс будет засчитан при размыкании — ровно один раз, без двойного счёта после пропадания питания.
